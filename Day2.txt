HTTP vs HTTPs
=============
HTTPs-->HTTPs is HTTP with Security through encryption

HTTP(Unsecured) -->Not Encrypted Best Suited for Local offline demos
-->Security risk is higher-->Data can be intercepted and exposed
-->Default port :80

HTTPs(Secured) -->Encrypted  via SSL and TSL
-->Best Suited for all real public websites ,data is protected
-->Default port:443


Request Response Cycle -->Flask
================================
Step1: Browser(User Initialise the action)

Step2: HTTP Request(Data sent to server)

Step3: Flask Route('/')(matches the url path)

Step4: Python Functions(Triggers mapped code)

Step5: Bussiness Logic (Process the Request)

Step6: HTTP Response (Formulate the answer back)

Step7: Browser(Render the Webpage)


Flask-->Micro Wed Framework
-------------------------------
-->Essential core functions and ake developers free to choose
   their own database,authentication and libaries
-->Creates Web Applications
--> Maps URLs dynamically to Python Functions
-->Flexible Outputs --->can return text,HTML,JSON APIs,files 
-->LightWeigth design -->Small to Medium apps

Ex:

from flask import Flask
app=Flask(__name__)
#@app.route() -->Decorator
@app.route('/about')    #about -->request URL
def home():   #function
    return "PFS-VSP-004 Students are good"

if __name__=="__main__":
      app.run()     #Local development server


**Trailing Slash Rules --> @app.route("/about/")
                     -->it will make both urls accessible/about will automatically
                       redirect to /about/

**Slash at end =Director ==Redirect
-->If we don't mention as above trailing slash only we have given 
  @app.route('/about')  -->No Slash=Exact
