Web Development 
-----------------
--->It refers to the overall process of creating,building and maintaining 
web applications or websites
--->It encompasses everything from plain text web pages to complex networks,
e-commerece platforms and real time web application

Web Development Broadly divided into two disciplines:
------------------------------------------------------
  --->Front End Development(Client Side) 
      -->Focuses on visual presentations,layouts and user interactivity using
          HTML5,CSS3,JS(React),UI   
  --->Back End Development(Server Side)
      -->It Focuses on Core Business logic,User authentication,data base operations,and APIs 
          using Languages such as Python,Java,Node,PHP

Full Stack Development -->It refers to the practice of working both on Frontend and Backend 
                           of a web development.A FullStack Developer posses the skills 
                           required to design a complete web application from scratch
                       -->Managing responsive user interfaces to managing server logic,
                         writing database quries and deploying applications to production servers  



Client-Server Architecture
===========================
--->It is a fundamental building block of Modern Web Infrastructure
                
                 HTTP Request(GET,POST)
Client(Browser)------------------------->Web Server
--------------                          -------------
HTML,CSS,JS  <-----HTML/JSON(200)      Flask Application(.py)
User Interface                         Business Logic/DB
(Chrome,safari,Edge)                   (WSGI/ngnix/Gunicorn)
                                       (Pythonanywhere,AWS)

Client --> Initialises requests for data or resources

Server --> Waits for incoming requests,process the request 
           (fetching the rows from a database)
           and returns the requested response back to the client
